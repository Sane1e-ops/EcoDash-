# Audio assets

The game uses these MP3s from `js/game.js`:

- `soundreality-forest-sound-576537.mp3` loops during active gameplay.
- `freesound_community-vintage-game-sound-58050.mp3` plays when a route starts.
- `epic_stock_media-ancient_game_dark_magic_buff_2_fantasy_tonal_accent_hit_stab-386295.mp3` plays for each completed delivery.
- `ribhavagrawal-achievement-video-game-type-1-230515.mp3` plays when all five deliveries are complete.
- `cartoon_music-glockenspiel-cute-ending-music-504467.mp3` loops after all five deliveries are complete until a new game starts.
- `dragon-studio-game-over-retro-8bit-sfx-499656.mp3` plays when the battery is depleted.

All sounds used in the are from pixabay.com
