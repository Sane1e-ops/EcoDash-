The wireframe was used to plan the main structure of the EcoDash interface before and during development.

The planned interface included:

Game header and title
Game map
Drone/player area
Navigation controls
Mission information
Destination information
Range and route progress
Battery and flight status
Objective tracking
Environmental information

The final interface was refined during development to improve readability and usability. Some elements were simplified or repositioned as the gameplay systems were implemented.
